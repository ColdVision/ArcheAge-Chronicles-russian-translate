# Русификатор ArcheAge Chronicles

Неофициальный фанатский русский перевод игры ArcheAge Chronicles (Steam). Перевод выполнен с нуля.

> Статус: **0.1.4 — ранняя версия** (игра: Steam buildid 26495283). Переведено 49 410 из 54 759 строк (90,2%; остальное — служебные строки). Ручная вычитка ещё не проводилась.

## Установка (для игроков)
1. Скачайте архив `ArcheAge-Chronicles-RU-<версия>.zip` из раздела **Releases**.
2. Распакуйте в папку игры и запустите один из файлов:
   - `Enable Full Russian.cmd` — версия **A**, всё на русском (рекомендуется);
   - `Enable English names.cmd` — версия **B**: тексты на русском, а названия предметов, локаций, умений, квестов и глав, имена NPC и фракций на английском.
3. После обновления игры или перевода запустите `Update-Russian.cmd`.
4. `Remove-Russian.cmd` — удалить перевод и вернуть английский язык.

Перевод ставится отдельным файлом `X5\Content\Localization\String\ru\String.locres` рядом с оригинальными языками; файлы игры (`.pak`) не изменяются. Установщик не содержит игровых файлов и ключей.

## Что внутри репозитория
| Путь | Назначение |
|---|---|
| `ru-installer/` | установщик для игроков (cmd + PowerShell) |
| `translation/glossary/` | глоссарии: имена и названия (`names.tsv`), умения (`skills.txt`), стиль переводов |
| `translation/scripts/` | сборка релиза, проверки, рабочие скрипты пачек |
| `translation/release-docs/` | README для архива, описание релиза, чек-лист теста |
| `tools-src/` | исходники инструмента перевода `x5tr` |

Рабочий проект перевода и оригинальные файлы игры в репозиторий не входят.

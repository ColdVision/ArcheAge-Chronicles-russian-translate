# План перевода (две версии из одного проекта)

Оригинал: `game-data\X5\Content\Localization\String\en\String.locres`, 54 711 строк.
Проект: `project\aa.x5tr`. Пробная пачка: `batches\000-trial.json` (143 строки, уже внутри проекта).

## Два варианта
- **A** — всё по-русски.
- **B** — названия предметов, локаций и умений (и статусов) остаются английскими: ключи из `glossary\variantB-keep.txt` берутся из оригинала целиком, а имена в тексте записаны маркером `{{n:id|падеж}}`.
- Сборка: `x5tr release project\aa.x5tr releases\X --version V --build B --variant A|B`
  (`--names`, `--keep`, `--b-kinds loc,item,skill` — по умолчанию из `glossary\`). Сборка падает, если остался маркер с неизвестным id.
- Падежи в маркере: nom gen dat acc ins prep. Предлоги и окончания пишутся вне маркера.
- Теги `<Ref>`, `<cms ... id>`, `<param>`, `<Icon>` игра подставляет сама (в варианте B названия подтянутся английскими из оставленных NAME-строк). После двоеточия лучше, чем склонять: «Соберите: <param/>».

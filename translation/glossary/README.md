# Глоссарий

`glossary.tsv` — таблица с табуляцией: `en`, `ru`, `категория`, `примечание`.
Категории: класс, навык, предмет, локация, персонаж, фракция, статус, интерфейс, прочее.

Правила:
- Термин добавляется **до** того, как попал в перевод, а не после.
- Одно английское слово — один русский вариант. Если нужны два, пишем в примечании, когда какой.
- Имена собственные и названия мест не переводим дословно, если у них нет устоявшегося русского варианта.
- Перед каждой пачкой: найти в `todo.json` повторяющиеся слова и свериться с глоссарием.
- Перевод свой; чужие русификации не копируем и не сверяем.

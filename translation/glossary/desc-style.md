# Описания предметов — правила (для субагентов)
Вход `n|English` → выход `n|Русский`, одна строка на номер, те же номера. ¶ = перенос строки: сохранять ВСЕ ¶ на тех же местах (их число должно совпасть).
Токены ⟦…⟧ и теги <…> копировать без изменений. Числа, %, +, проценты, параметры — без изменений.
Стиль: литературный русский, художественные цитаты в кавычках-ёлочках «…» (английские "…" → «…»). Описания эффектов — кратко, в настоящем времени («Восстанавливает…», «Повышает…»). Обращение к игроку — «вы».
Названия предметов, если упомянуты в тексте, переводить по glossary/items-style.md. HP оставлять HP. SP → {{n:sp|падеж}} (выносливость), например {{n:sp|acc}}, {{n:sp|gen}}.
Имена собственные: Auroria → {{n:auroria|падеж}} (Аврория); Black Iron → чёрное железо; Hereafter → Загробье; Hersander → Херсандер; Nui → Нуи; Azhra → Ажра; Gylden → Гильден; Lunastone → лунный камень; Lunagem → лунный самоцвет; Archeum → археум; Rancor → злоба; Trait → черта; Proficiency → мастерство; Guild → гильдия; Company → компания; Trade Goods → торговые товары. Прочие имена и места — естественная русская транскрипция/перевод.
Повторяющиеся английские фразы переводить одинаково.
Тестовые/служебные строки (test, dummy, TBD) вернуть без изменений.

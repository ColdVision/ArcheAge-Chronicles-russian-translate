# Диалоги — правила (для субагентов)
Вход `n|English` → выход `n|Русский`, одна строка на номер. ¶ = перенос строки: сохранять ВСЕ ¶. Токены ⟦…⟧ копировать без изменений (каждый столько же раз). Начальные пробелы/табы можно убрать.
Строки идут подряд по ключам: соседние строки обычно — одна сцена, держите единый тон и обращение.
- DIALOGUE_…_TEXT — реплики NPC. Живой разговорный русский. Простые NPC (крестьяне, торговцы, бойцы, бандиты) говорят герою «ты»; официальные лица, знать, капитаны, жрецы в официальной речи — «вы». Внутри одной сцены не менять ты/вы.
- DIALOGUESELECTION_…_TEXT — реплики героя (варианты ответа). Коротко, разговорно. Действия в скобках: «(Show the Black Iron fragment)» → «(Показать фрагмент чёрного железа)».
- Пол героя неизвестен: не используйте прошедшее время с родом для героя ни в репликах героя, ни в обращении к нему («ты пришёл» → «ты здесь», «ты справился» → «у тебя получилось», «я видел» → «мне довелось увидеть»). Род NPC определяйте по контексту, если ясно.
- CHANGESPEAKERNAME — имя говорящего: только имя/звание, без точки.
Мир: Erenor = Эренор; Auroria → {{n:auroria|падеж}} (Аврория). Остальные термины и имена — glossary/quest-style.md, glossary/items-style.md, glossary/desc-style.md. Одно имя — везде одинаково. SP → {{n:sp|падеж}}, HP оставлять. Кавычки «…». Технические/тестовые строки вернуть без изменений.

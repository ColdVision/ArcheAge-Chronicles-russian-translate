# Имена NPC — правила (для субагентов)
Вход `n|English` → выход `n|Русский`, одна строка на номер. Токены ⟦…⟧ копировать без изменений.
- Строки, начинающиеся с «-----» (служебные разделители разработчиков), вернуть БЕЗ изменений.
- Имена собственные — естественная русская транскрипция (Mungo = Мунго, Rodoth = Родот). Уже принятые имена/места — строго по glossary/known-names.txt.
- Описательные имена и звания переводить: «City Guard» = «Городской стражник», «Bandit Archer» = «Бандит-лучник», «Merchant Vadim» = «Торговец Вадим», «Wild Boar» = «Дикий кабан». Монстры — естественно по-русски.
- Конструкции «Имя the Эпитет» = «Имя Эпитет» (Vesper the Ruthless = Веспер Безжалостный).
- NICKNAME — прозвище/подпись под именем (кратко, с маленькой буквы, если это должность: «торговец», «кузнец»).
- NPCGROUP — название группы/фракции.
- Одинаковые слова переводить одинаково во всех строках (Guard = стражник, Captain = капитан, Merchant = торговец, Pirate = пират, Cultist = культист, Elite = элитный, Boss = босс).
Термины мира: glossary/quest-style.md, glossary/items-style.md.

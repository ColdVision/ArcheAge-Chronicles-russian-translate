# Квесты — правила (для субагентов)
Вход `n|English` → выход `n|Русский`, одна строка на номер. ¶ = перенос строки: сохранять ВСЕ ¶ (их число должно совпасть).
Токены ⟦…⟧ (⟦t1⟧ — подставляемое игрой название/параметр, ⟦k1⟧ — кнопка и т.п.) копировать без изменений, каждый ровно столько же раз. Технические строки (вида `1000010+B+[@id]`, test, dummy) вернуть без изменений.
Типы строк:
- NAME — название задания: кратко, без точки («Потерянное письмо», «Соберите ⟦t1⟧» → для «Collect ⟦t1⟧» пишите «Сбор: ⟦t1⟧»).
- PROGRESSDESC — цель задания: повелительно-инфинитивно кратко: «Craft ⟦t1⟧» = «Создать: ⟦t1⟧», «Deliver ⟦t1⟧» = «Доставить: ⟦t1⟧», «Defeat X» = «Победить: X», «Talk to X» = «Поговорить: X», «Go to X» = «Отправиться: X». Конструкция «Глагол: объект» обязательна, когда объект — токен (падеж неизвестен).
- DESC / QUESTCOMPLETEDESC — описание сюжета: живой литературный язык. Реплики NPC (если есть) разговорные: простым NPC на «ты» к герою, официальные лица — на «вы». Пол героя неизвестен: избегайте прошедшего времени с родом для героя («ты сделал») — используйте нейтральные конструкции («у тебя получилось», «спасибо за помощь»).
Термины: см. glossary/items-style.md и glossary/desc-style.md (Auroria → {{n:auroria|падеж}}, Hereafter=Загробье, Lunastone=лунный камень, Archeum=археум, Rancor=злоба, Nui=Нуи, Black Iron=чёрное железо, Dark Blades=Тёмные Клинки, Hand of Trust=Рука Доверия, Bluesalt Brotherhood=Братство Синей соли, Crimson Watch=Багровый дозор, Antiquary Society=Общество антикваров, Seaglass Harbor=Гавань Морского Стекла, Gylden Ruins=Гильденские руины, Astron Plains=Равнины Астрона, Diamond Shores=Алмазные берега). Имена людей: Gartez=Гартез, Slin=Слин, Tristan=Тристан, Vesper=Веспер, Meliot=Мелиот, Vadim=Вадим, Malchuk=Мальчук, Donella=Донелла, Yon=Ён, Zudaka=Зудака, Engreven=Энгревен. Прочие имена — естественная транскрипция; одно имя пишите везде одинаково.

# Русский перевод ArcheAge Chronicles

Неофициальный фанатский перевод игры на русский язык. Ранняя версия: текст переведён полностью, но **без ручной вычитки**.

## Две версии перевода
- **A — полностью на русском** (рекомендуется): переведено всё, включая названия предметов, локаций, умений, имена NPC и фракций.
- **B — с английскими названиями**: все тексты, диалоги и интерфейс на русском, но названия предметов, локаций, умений и статусов, квестов и глав сюжета, имена NPC и фракций остаются английскими (описания и цели квестов — на русском) (удобно, если вы играете с английскими гайдами, базами и сообществом). Пример: «Отправляйтесь в Seaglass Harbor и найдите Gartez».

Сменить версию можно в любой момент: просто запустите файл другой версии — прежний файл будет заменён, лишнего не останется. `Update-Russian.cmd` обновляет ту версию, что установлена.

## Что внутри
- `Enable Full Russian.cmd` — установить и включить версию **A** (полностью на русском).
- `Enable English names.cmd` — установить и включить версию **B** (английские названия и имена).
- `Update-Russian.cmd` — проверить и установить новую версию перевода.
- `Remove-Russian.cmd` — полностью удалить перевод и вернуть английский.
- `variants/A/…/String.locres`, `variants/B/…/String.locres` — файлы перевода, `release-manifest-A.json` / `release-manifest-B.json` — их описание с контрольными суммами.
- `tools/` — служебные файлы установщика.

## Установка
1. Закройте игру и лаунчер.
2. Распакуйте архив целиком в папку игры — туда, где лежит `ArcheAgeChronicles.exe` (в Steam: ПКМ по игре → Управление → Показать локальные файлы). Можно распаковать и в любое другое место: установщик сам найдёт игру в Steam.
3. Запустите `Enable Full Russian.cmd` (версия A) или `Enable English names.cmd` (версия B).

Установщик кладёт файл `X5\Content\Localization\String\ru\String.locres` рядом с оригинальными языками и прописывает `Culture=ru` в `%LOCALAPPDATA%\X5\Saved\Config\Windows\GameUserSettings.ini`. Файлы игры (`.pak`) не изменяются. Перед заменой проверяется контрольная сумма.

Если игра осталась на английском: в Steam → Свойства игры → Параметры запуска добавьте `-culture=ru`.

## Обновление
Запустите `Update-Russian.cmd`. Установщик сверит версию с последним релизом на GitHub и, если есть новая, скачает и установит её. Без интернета будет использован файл из папки.

После обновления самой игры часть изменившихся строк может временно оставаться на английском — запускайте `Update-Russian.cmd`, когда выйдет новая версия перевода.

## Удаление
- `Remove-Russian.cmd` — удаляет установленный файл перевода и включает английский. Если вы добавляли `-culture=ru` в параметры запуска Steam, удалите его.
